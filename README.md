# Моделирование игровых интеллектуальных агентов в среде Unity

**Автор:** Костюк Дмитрий Степанович

---

## О проекте

Этот репозиторий содержит исследовательский Unity-проект, посвящённый интеллектуальным агентам в среде Unity. В этом игровом проекте реализован небольшой RPG прототип, а также ИИ-противники, которые управляются разными архитектурами
